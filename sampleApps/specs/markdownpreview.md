## 1. 目的 / 背景
Markdown 形式で書かれたファイルをプレビューする機能を提供する。Edge ブラウザの拡張機能として実装し、ドラッグ＆ドロップまたはファイル選択ダイアログでファイルを開くことで、ブラウザ上で Markdown を整形したビューを閲覧できる。

## 2. スコープ
- 対象: .md ファイルの読み込みと整形表示（プレビュー）、拡張機能内での本文編集と保存（ダウンロード）
- 対象外: 元ファイルへの直接上書き保存（保存は別ファイルへのダウンロードとする）

## 3. 用語
| 用語 | 定義 |
|---|---|
| 拡張機能 | Edge ブラウザにインストールして動作する本機能 |
| プレビュー | Markdown 記法を HTML に変換して整形表示した状態 |
| CommonMark | Markdown の標準仕様 |
| GFM | GitHub Flavored Markdown。CommonMark に表・タスクリスト・打消し線等を加えた拡張 |
| Mermaid | テキスト記法で図を定義する図表ツール（本機能で対応する図記法） |
| PlantUML | テキスト記法で図を定義する UML ツール（本機能では対象外・将来対応） |

## 4. 要件
| 仕様No | 要件 | 優先度 |
|---|---|---|
| SPEC-001-R1 | .md ファイルを、ドラッグ＆ドロップまたはダイアログボックスから指定できる | must |
| SPEC-001-R2 | .md ファイルを Markdown（CommonMark + GFM。表・コードブロック・チェックボックス等を含む）として解釈し、プレビューできる | must |
| SPEC-001-R3 | 編集ボタンを押すと拡張機能内で本文を編集でき、編集内容をテキストファイルとして保存（ダウンロード）できる。保存時の文字コードは UTF-8 とする。編集内容はプレビューに再描画される | should |
| SPEC-001-R4 | Mermaid 記法で書かれたコードブロックを図として表示できる（PlantUML は対象外・将来対応） | could |
| SPEC-001-R5 | 指定されたファイルが .md でない場合、「.md ファイルを選択してください」と表示され、プレビューは実施されない | must |
| SPEC-001-R6 | UTF-8・Shift-JIS の文字コードのファイルを、文字化けなく表示できる。文字コードは自動判定し、判定できない場合は UTF-8 として扱う | should |
| SPEC-001-R7 | 保存時に元ファイルと異なる文字コードで書き出す場合、変更後の文字コードが分かるメッセージを表示する | should |
| SPEC-001-R8 | ファイルサイズが上限（5MB = 5,242,880 バイト）を超える場合、警告を表示しプレビューを実施しない。空ファイルの場合は空のプレビューを表示する（エラーにしない） | should |

## 5. 受入れ条件

- **SPEC-001-R1（ファイルの指定）**
  - 正常系（ドラッグ＆ドロップ）
    - Given 拡張機能のプレビュー画面が開いている
    - When .md ファイルがプレビュー画面のドロップ領域にドラッグ＆ドロップされる
    - Then そのファイルが読み込まれ、プレビューが表示される
  - 正常系（ダイアログ）
    - Given 拡張機能のファイル選択ダイアログが開いている
    - When .md ファイルを選択して開く
    - Then そのファイルが読み込まれ、プレビューが表示される

- **SPEC-001-R2（Markdown のプレビュー）**
  - 正常系: 記法の変換
    - Given `# 見出し` と `**太字**` と `- 箇条書き` を含む .md ファイルが読み込まれている
    - When プレビューを表示する
    - Then `# 見出し` は `<h1>`、`**太字**` は `<strong>`、`- 箇条書き` は `<ul><li>` として描画される
  - 準正常系: Markdown として解釈できない行
    - Given Markdown 記法として解釈できない行を含む .md ファイルが読み込まれている
    - When プレビューを表示する
    - Then その行はプレーンテキストとしてそのまま表示され、エラーは出ない

- **SPEC-001-R3（拡張内編集・保存・再描画）**
  - 正常系: 編集
    - Given .md ファイルが読み込まれ、プレビューが表示済み
    - When 編集ボタンを押下する
    - Then 本文が編集可能な状態（テキスト入力欄）で表示される
  - 正常系: 再プレビュー
    - Given 編集可能な状態で本文を変更した
    - When プレビュー（再描画）を実行する
    - Then 変更後の内容が Markdown として整形表示される
  - 正常系: 保存
    - Given 本文を編集した状態
    - When 保存を実行する
    - Then 編集内容が UTF-8 のテキストファイルとしてダウンロードされる

- **SPEC-001-R4（Mermaid 図の表示）**
  - 正常系
    - Given Mermaid 記法で書かれたコードブロック（```mermaid）を含む .md ファイルが読み込まれている
    - When プレビューを表示する
    - Then 該当ブロックが図としてレンダリングされ表示される
  - 準正常系: 不正な Mermaid 記法
    - Given 構文エラーのある Mermaid コードブロックを含む .md ファイルが読み込まれている
    - When プレビューを表示する
    - Then 図の描画は失敗するが、他の内容のプレビューは継続して表示される

- **SPEC-001-R5（対象外ファイルの拒否）**
  - 異常系
    - Given 拡張機能のプレビュー画面が開いている
    - When .md でないファイルがプレビュー画面のドロップ領域にドラッグ＆ドロップされる
    - Then 「.md ファイルを選択してください」と表示され、プレビューは実施されない

- **SPEC-001-R6（文字コード対応）**
  - 正常系: UTF-8
    - Given UTF-8 で保存された日本語を含む .md ファイルが読み込まれている
    - When プレビューを表示する
    - Then 日本語が文字化けせず正しく表示される
  - 正常系: Shift-JIS
    - Given Shift-JIS で保存された日本語を含む .md ファイルが読み込まれている
    - When プレビューを表示する
    - Then 日本語が文字化けせず正しく表示される

- **SPEC-001-R7（文字コード変更の通知）**
  - 正常系: コードが変わる場合
    - Given Shift-JIS で読み込んだファイルを編集している（保存は UTF-8 固定）
    - When 保存を実行する
    - Then 「UTF-8 で保存しました」のように、変更後の文字コードが分かるメッセージが表示される
  - 正常系: コードが変わらない場合
    - Given UTF-8 で読み込んだファイルを編集している（保存は UTF-8 固定）
    - When 保存を実行する
    - Then 文字コード変更の通知は表示されない

- **SPEC-001-R8（ファイルサイズ・空ファイル）**
  - 異常系: サイズ超過
    - Given 5,242,880 バイト（5MB）を超える .md ファイルを指定した
    - When 読み込もうとする
    - Then サイズ超過の警告が表示され、プレビューは実施されない
  - 準正常系: 空ファイル
    - Given 中身が空の .md ファイルを指定した
    - When プレビューを表示する
    - Then 空のプレビューが表示され、エラーは出ない

## 7. 決定事項（旧・未決事項）
実装方針として確定済み。詳細な実装手段は設計書 `design/markdownpreview.design.md` 参照。

- Markdown 範囲（R2）: **CommonMark + GFM**（表・コードブロック・タスクリスト等を含む）。
- 保存（R3）: ダウンロード方式（別ファイル）。元ファイルへの直接上書きは対象外（将来の拡張余地）。保存文字コードは **UTF-8 に統一**（標準 TextEncoder が UTF-8 のみのため）。元と異なる場合は R7 で通知。
- 図（R4）: **Mermaid のみクライアント描画**で対応。PlantUML は外部サーバ依存のプライバシー懸念があるため対象外（将来対応）。
- 文字コード（R6）: **UTF-8・Shift-JIS** を自動判定（判定ライブラリ利用）。判定不能時は UTF-8 として扱う。EUC-JP・UTF-16 等は当面対象外。
- ファイル境界（R8）: サイズ上限 **5MB（5,242,880 バイト）**、空ファイルは空プレビュー表示。

## 8. 残課題 / 将来対応
- PlantUML の図表示（外部サーバ利用時のプライバシー方針とあわせて検討）
- 対応文字コードの拡張（EUC-JP・UTF-16 等）
- 元ファイルへの上書き保存（File System Access API の制約を踏まえた検討）

## 0-1. ワークショップのタイトル（スライド1）

> **Claude Code AI駆動開発ワークショップ**
> Prompt → Context → Harness
> アジャイル × 仕様駆動開発 × AI

2日間で学ぶのは **「指示の技術」の 3 段階進化** です：

```
Prompt → Context → Harness
 ↑         ↑        ↑
何を聞くか  何を見せるか  どう動かすか
```

この順番は、過去 3 年間の AI 開発のベストプラクティスの変遷そのものでもあります。

---

## 0-2. この教育の位置づけ（スライド3）

### Claude Code は毎週 40–60 件更新される

CHANGELOG を見てみてください。**「毎週 40–60 件の変更がリリース」** されています（2025年3月〜4月の実績）。

→ 今日できないことも、明日はできるかもしれない。
→ 今日の制約は、来週には解消されているかもしれない。

### だから今日持ち帰ってほしいこと（3つ）

1. **教えられたことはいつまでも正しいわけではない**
   ツールの進化速度が、人間の学習速度を超えている。
2. **「原理」を学び「操作」に固執しない**
   具体的な操作手順はすぐ変わる。けれど **原理（Agent = Model + Harness）** を理解すれば変化に対応できる。
3. **公式ドキュメントと Changelog が最新の教科書**
   WS の資料より公式が常に正しい。変更を追い続ける習慣が最大の武器になる。

## 0-3. 2日間のアジェンダ（全体像）

このワークショップは **連続2日・午後×2（各4h）** で組み立てられています。

```
Day1（午後） 原理 + Context Engineering
  ├─ 原理編（AI エージェントとは / 開発手法の変遷）
  ├─ 体験① Vibe Coding（デモ＋限界診断）
  ├─ SDD 理論・CLAUDE.md・Skills / Agents / MCP
  └─ 体験② SDD ハンズオン

  [自宅課題 30〜40分: 日報アプリ題材で 5 工程の AI ハーネス構成を設計 → Day2 冒頭で発表]

Day2（午後） Harness Engineering 本編 + スケール
  ├─ Hooks 入門
  ├─ 体験③ Agentic × SDD（Hooks + Agents + 委譲）
  ├─ 体験④ TDD Guard 再実装（Skills + Hooks + Plugin 化）
  ├─ エージェントアーキテクチャ深掘り
  └─ スケール編：AI駆動開発 3層スタンダード
```

### 受講アンケートを踏まえた重心

事前アンケートで寄せられた声：

- 「Vibe Coding はある程度経験済み」 → **体験① は短縮**、デモ＋限界診断中心に
- 「Harness Engineering への興味が最も大きい」 → **Hooks / 体験③ / 体験④ を厚盛り**
- 「体系的に学べる教材がなくて困っている」 → **原理編と Skills/Agents/MCP 講義はフルに**、さらに **3層スタンダード（20分）** を追加

## 0-4. 今日からの心構え

- **コードを書けない時間も学びである** — 原理の章が長いのは意図です
- **質問は溜めない** — Claude Code は毎週変わるので、古い情報と最新を切り分けるために、気になったらその場で聞く
- **隣の人と比べない** — Vibe 経験が全員違います。自分の「腹落ち」を優先してください

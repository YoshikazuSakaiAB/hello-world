## 1-1. AI エージェントとは？（スライド5）

### 従来の AI ツール vs AI エージェント

| | 従来の AI ツール | AI エージェント |
|---|---|---|
| モード | 人間が入力 → AI が応答 → 終了 | 目標 → 理解 → 計画 → 実行 → 検証 |
| 状態 | 1回のやりとりで完結（ステートレス） | 自律的にループ（Goal-driven） |
| 例 | ChatGPT 初期 | Claude Code |

### 最重要公式：`Agent = Model + Harness`

```
Agent = Model + Harness
         ↑         ↑
       LLMの頭脳   CLAUDE.md + Skills + Hooks + Agents + MCP + 権限
```

> **ハーネスの設計が品質の 80% を決める** — 同じモデルでもハーネス次第で結果が変わる。

この式は、2日間ずっと参照する「北極星」です。

## 1-2. Tool — AI の「手」（スライド6）

**LLM 単体では「考える」ことしかできない**。ツールを与えることで **行動** が可能になる。

```
ツールなしの LLM         ツールを持った AI エージェント
-------------            ---------------------
質問に答える             ファイルを読み書き
文章を生成する           コマンドを実行
翻訳する                 Web を検索
                         DB に接続
→ テキストの入出力だけ    → 現実世界に作用できる
→ 外の世界に触れない      → 自律的にタスクを遂行
→ ChatGPT の初期がこれ    → Claude Code がこれ
```

### Claude Code が持つ主要ツール

| ツール | 役割 |
|---|---|
| `Read` | ファイルを読む |
| `Write` | ファイルを書く |
| `Edit` | ファイルを編集 |
| `Bash` | コマンド実行 |
| `Glob` | ファイル検索 |
| `Grep` | テキスト検索 |
| `Agent` | サブエージェント生成 |
| `MCP` | 外部サービス連携 |

> **ツール = AI が世界に作用する手段。Hooks はツール実行の前後に品質ゲートを挟む仕組み。**

## 1-4. 「指示の技術」の進化（スライド8）

```
2023-24         2025             2026–
Prompt      →   Context      →   Harness
Engineering     Engineering      Engineering

何を聞くか       何を見せるか     どう動かすか

プロンプトの    CLAUDE.md       Hooks・テスト
テクニック      仕様書・RAG     権限制御
```

> **モデル性能が上がるほど、「プロンプトの工夫」より「環境の設計」が成果を決める。**

この進化を 3 体験で辿ります：

- 体験①（Day1）= Prompt Engineering
- 体験②（Day1）= Context Engineering
- 体験③④（Day2）= Harness Engineering

---

## 1-5. AI 駆動開発の 3 ステージ（スライド9）

| Stage | 名称 | 流れ | 評価 |
|---|---|---|---|
| 1 | **Vibe Coding** | 人間「〇〇作って」→ AI が即興で実装 → 人間が目視で確認 | 速いが品質は運次第 |
| 2 | **SDD（人間主導）** | 人間が仕様を書く → 人間がタスク分割 → AI が1つずつ実装 | 品質↑ だが仕様作成が負荷 |
| 3 | **Agentic × SDD** | 人間「〇〇作って」→ AI が仕様+タスク+テスト生成 → AI が自律で実装&検証 | Vibe の UX × SDD の品質 |

> **Stage 3 = 「〇〇作って」だけで仕様もテストも AI が自律生成。Vibe の手軽さ × SDD の品質。**

### 今日のゴール

Stage 3 を **自分の手で組める** 状態になる。そのために Stage 1 → 2 → 3 を順に辿ります。

---

## 1-6. この章のまとめ

- `Agent = Model + Harness` — 品質の 80% はハーネス次第
- Tool は AI の「手」、Hooks はツール実行の前後に挟む品質ゲート
- 「指示の技術」は **Prompt → Context → Harness** と進化してきた
- AI 駆動開発は **Vibe → SDD → Agentic** の 3 ステージ

この言葉を持ち帰れれば第1章は成功です。

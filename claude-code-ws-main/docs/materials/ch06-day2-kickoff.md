## 6-2. 3 つの体験 × 3 つのパラダイム（スライド33）

Day1 でやったことの位置付けを整理します。

| パラダイム | 今日の体験 | Claude Code で | 人間の役割 |
|---|---|---|---|
| **Prompt Eng.** | 体験① Vibe Coding | 自然言語で直接指示 | 人間が全てを**操作**する |
| **Context Eng.** | 体験② SDD（仕様駆動） | CLAUDE.md + 仕様書 | 仕様で AI を**ガイド**する |
| **Harness Eng.** | 体験③ Hooks + Agents | 自動テスト・委譲 | 仕組みが品質を**担保**する |

```
体験① → 体験② → 体験③
  ↓         ↓         ↓
操作する → 設計する → 監督する
```

Day2 は **監督する人** になるための 4 時間です。

# Layer 2 — AI 出力スキーマ定義

AI が生成する各文書の **構造・必須項目・品質基準の型定義** です。
テンプレートは「人が埋めるフォーマット」ではなく、**AI への出力契約（スキーマ）** として機能します。

## 狙い

- AI が生成する文書の構造を**型で制約**する
- 必須項目・品質基準を明文化し、AI が自動で検証可能にする
- 文書間のトレーサビリティ（要求 → 仕様 → テスト → 実装）を担保する

## スキーマが満たすべき要素（共通）

各スキーマドキュメントには以下を含めます：

1. **目的** — この文書で何を表現するか
2. **入力ソース** — この文書を生成するために AI が参照すべき情報
3. **必須セクション** — 抜けると文書として不十分になる構造
4. **必須項目** — 各セクション内で必須の項目
5. **品質基準** — 検証可能な受入条件
6. **トレーサビリティ** — 上流・下流の文書への参照規則
7. **出力例** — 最小限のスニペット

## 配置先
